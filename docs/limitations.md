# Limitations

- This is a diagnostic artifact and tool prototype, not a mature production memory system.
- StateBind does not claim retrieval always fails. Retrieval can succeed when the active record and executable handle are cleanly exposed.
- The practical handoff helper is conservative and heuristic. It drafts handoffs; a human or agent should verify evidence before acting.
- Fully natural deployed-agent handoff corpora remain an important next step.
- Learned construction from messy traces is a separate research problem from consuming a correct binding tuple.
